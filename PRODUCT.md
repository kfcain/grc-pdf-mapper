# PRODUCT.md

## Register

product

## Platform

web

## Users

GRC analysts, security engineers, and compliance owners who already keep policy files on disk and run this tool locally.

## Purpose

Turn a local policy file into readable control mappings without using the CLI. The user chooses a file, the app parses it, and the app shows obligations and framework hits.

## Positioning

A quiet local workbench for policy ingest — not a SaaS dashboard, not a marketing site.

## Brand personality

Institutional, precise, calm under pressure. Think night audit desk: charcoal surface, moss indicator light, monospace control ids.

## Anti-references

- Purple-on-black AI SaaS shells
- Cream / parchment “editorial” landing pages
- Metric-card grids with glow accents
- Rounded-full pill clusters and badge soup
- Inter / Roboto / generic system-default marketing kits

## Design principles

1. One job per screen: choose a file, read the parse.
2. Data before decoration — obligations and control ids lead.
3. Dark by default; light only if the OS forces a preference later.
4. Familiar product affordances (drop zone, table, tabs) over invented chrome.
5. Failures are plain and fixable (missing optional deps, bad file type).

## Accessibility

WCAG AA contrast on body and controls. Keyboard operable drop zone and tabs. Respect `prefers-reduced-motion`.
